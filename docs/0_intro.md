# ВСТУП

## Актуальність теми
Сучасна індустрія інтерактивних програмних систем вимагає переходу від класичних перевантажених графічних інтерфейсів користувача (GUI) до дієгетичних систем та контекстної взаємодії, що підвищує рівень занурення користувача. Основна інженерна проблема полягає у запобіганні надмірній зв’язності компонентів (High Coupling) між підсистемами сценарію, станами оточення, поведінкою NPC та системою предметів. Складність полягає в детермінованій обробці сценарних тригерів, забезпеченні надійної серіалізації стану світу та створенні гнучкої архітектури взаємодії.

## Об'єкт дослідження
Процес функціонування та обробки контекстно-залежних даних взаємодії користувача з інтерактивними об'єктами та сценарними тригерами в сюжетно-орієнтованих програмних системах.

## Предмет дослідження
Архітектурні патерни проектування (Event Bus, State Machine, Service Locator), механізми модульної декомпозиції на базі ScriptableObjects та алгоритми серіалізації даних на базі інструментарію рушія Unity та мови C#.

## Мета роботи
Проєктування та програмна розробка модульної клієнтської відеоігрової системи в жанрі психологічного трилера шляхом застосування подієво-орієнтованих патернів та скінченних автоматів для мінімізації архітектурної зв'язності коду, оптимізації затримок контекстної обробки подій та забезпечення детермінованої серіалізації ігрових станів.

## Завдання проєкту
1. Проаналізувати наявні архітектурні рішення, аналоги та патерни побудови сюжетно-орієнтованих інтерактивних систем відповідно до стандартів ДСТУ.
2. Обґрунтувати вибір технологічного стеку, модульної структури даних на основі ScriptableObjects та інструментарію забезпечення якості коду.
3. Спроєктувати високорівневу архітектуру системи (UML діаграми класів, компонентна C4 Model, схема скінченних автоматів переходу станів квестів).
4. Розробити алгоритми функціонування контекстного менеджера взаємодії, вузлового рушія діалогів та поведінкових FSM для NPC.
5. Спроєктувати інтерфейс дієгетичного віртуального термінала та схему автоматизованого розгортання й збірки (CI/CD Pipeline).
6. Провести інструментальний аудит коду, модульне та інтеграційне тестування розроблених систем із використанням Unity Test Framework.
7. Здійснити науково-практичну апробацію отриманих інженерних результатів шляхом підготовки доповіді або фахової публікації.
