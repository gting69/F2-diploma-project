\# Thesis Proposal: Проєктування та розробка корпоративної інтелектуальної бази знань підприємства за архітектурою GraphRAG



\## 1. Актуальність та проблематика



Традиційні підходи до пошуку інформації на базі векторних сховищ (RAG) втрачають контекст при обробці складних багатоаспектних зв'язків між сутностями всередині великих масивів корпоративної документації. Проблема полягає у відносному «роздробленні» знань і нездатності стандартних ембеддінгів знаходити глибокі логічні зв'язки. Проєкт вирішує задачу розробки гібридної системи GraphRAG, яка поєднує семантичний пошук та граф знань для забезпечення високої точності генерації відповідей на основі внутрішніх даних підприємства.



\## 2. Сформована ідея продукту



Корпоративна інтелектуальна система керування знаннями на базі Python (FastAPI), що автоматично генерує графи знань за допомогою LLM із неструктурованих документів, зберігає їх у графовій СУБД (Neo4j) та здійснює гібридний семантичний пошук.



\## 3. Детальний опис функціоналу (Core Features)



1\. Модуль автоматизованого парсингу та попередньої обробки корпоративних текстових документів (PDF, Markdown, DOCX).

2\. Інтеграція з LLM для автоматичного виділення сутностей та побудови графа знань (Knowledge Graph).

3\. Зберігання та управління графовою структурою зв'язків у високопродуктивній СУБД Neo4j.

4\. Реалізація оркестрації агентних воркфлоу та взаємодії з моделлю за допомогою бібліотеки LangGraph.

5\. Гібридний пошуковий механізм (Graph + Vector Search) для знаходження контекстуально релевантної інформації.

6\. REST API інтерфейс на базі FastAPI для забезпечення взаємодії з клієнтськими застосунками.



\## 4. Попередній інструментарій та технологічний стек



\- \*\*Мови програмування:\*\* Python 3.11+

\- \*\*Архітектурні патерни:\*\* Clean Architecture, Graph-based Retrieval-Augmented Generation (GraphRAG), RESTful API

\- \*\*Фреймворки та бібліотеки:\*\* FastAPI, LangGraph, Pydantic, ChromaDB

\- \*\*Бази даних:\*\* Neo4j (Графова СУБД), PostgreSQL (для метаданих)

\- \*\*DevOps-інструменти:\*\* Docker, Docker Compose, Git
