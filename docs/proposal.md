# Кваліфікаційний проєкт (Thesis Proposal)

## 1. Паспорт проєкту
* **Тема (укр.):** Проєктування та розробка програмної системи відеогри в жанрі психологічного трилера з контекстною взаємодією та модульним наративом на рушії Unity
* **Topic (eng.):** Design and Development of a Psychological Thriller Video Game Software System with Contextual Interaction and Modular Narrative on the Unity Engine
* **Здобувач:** Кирилова Емілі Геннадіївна (група F2, спеціальність 121 «Інженерія програмного забезпечення»)
* **Науковий керівник:** Танащишена Інесса Євгеніївна

---

## 2. Актуальність та проблематика
Сучасна розробка сюжетно-орієнтованих відеоігор вимагає відходу від перевантажених графічних інтерфейсів на користь дієгетичних систем та контекстної взаємодії, що підвищує рівень занурення користувача. Основна інженерна проблема полягає у запобіганні надмірній зв’язності компонентів (High Coupling) між підсистемами сценарію, станами оточення, штучним інтелектом неігрових персонажів (NPC) та системою інвентарю. Складність полягає в оптимізації обробки сценарних тригерів, забезпеченні надійної детермінованої серіалізації ігрового стану та реалізації гнучкого графа квестів, незалежного від способу рендерингу (2D/3D).

---

## 3. Сформована ідея продукту
Програмний комплекс являє собою модульну клієнтську відеоігрову систему з подієво-орієнтованою архітектурою (Event-Driven Architecture). Ядро системи забезпечує контекстну фільтрацію дій без використання масивного GUI, підтримує вбудовану модульну підсистему віртуального пристрою (дієгетичний інтерфейс зв'язку/інспекції) та реалізує сценарний механізм на основі скінченних автоматів.

---

## 4. Ключовий функціонал (Core Features)
1. **Контекстний менеджер взаємодії (Contextual Interaction System):** Виявлення інтерактивних об'єктів у радіусі дії гравця з автоматичною верифікацією передумов (наявність ключів, стан квесту) без рутинного відкриття вікон інвентарю.
2. **Модульний наративний рушій (Node-based Narrative & Dialogue System):** Механізм обробки нелінійних діалогових гілок із підтримкою умовних переходів та генерацією сценарних подій.
3. **Підсистема керування станами квестів (Quest State Machine):** Децентралізоване відстеження прогресу проходження на базі розширених ScriptableObjects із трансляцією подій у Event Bus.
4. **Адаптивні поведінкові моделі NPC (Behavioral FSM):** Зміна станів поведінки персонажів (пасивний, спостереження, реакція на оточення) на основі тригерних зон та сценарних маркерів.
5. **Ізольований модуль віртуального термінала:** Автономна підсистема інтерфейсу для відтворення локальних міні-ігор та розшифровки сюжетних даних.
6. **Підсистема персистентності та серіалізації:** Надійне збереження повного стану ігрового світу у форматі JSON із валідацією контрольних сум для захисту від спотворення даних.

---

## 5. Попередній інструментарій та технологічний стек
* **Мова програмування:** C# (.NET 8 / Unity Core API).
* **Ігровий рушій та середовище:** Unity Engine (LTS-версія, URP).
* **Архітектурні патерни:** State (кінцеві автомати), Event Bus (подієва шина), Service Locator / Dependency Injection, Observer, Command.
* **Керування даними та персистентність:** ScriptableObjects для статичних конфігурацій, JSON.NET / Binary Serialization для зберігання динамічних станів.
* **Тестування та інженерія якості:** Unity Test Framework (Unit/Integration Tests), NUnit.
* **DevOps та інфраструктура документування:** Git (Docs-as-Code контур), GitHub Actions (автоматична збірка та перевірка коду лінтером), Markdown.

* **Статус верифікації:** Концепт попередньо погоджено науковим керівником (Танащишена І.Є.).
