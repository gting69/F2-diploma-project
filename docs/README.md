## Зведена матриця нефункціональних вимог (NFRs Matrix)

| Ідентифікатор | Категорія | Інженерний параметр / Метрика | Цільове значення |
| :--- | :--- | :--- | :--- |
| **SRS-NFR-PERF-01** | Продуктивність | Цільовий фреймрейт рендерингу | **60 FPS** ($\le 16.6$ мс/кадр) |
| **SRS-NFR-PERF-02** | Швидкодія | Latency подій у Event Bus (p95) | $\le$ **5 мс** |
| **SRS-NFR-MEM-01** | Керування пам'яттю | Виділення оперативної пам'яті (GC Alloc) | $\le$ **10 КБ / кадр** |
| **SRS-NFR-DATA-01** | Персистентність | Час серіалізації/десеріалізації стану | $\le$ **50 мс** |
| **SRS-NFR-SEC-01** | Безпека | Верифікація цілісності сейвів | Гешування **SHA-256** |
| **SRS-NFR-QUAL-01** | Надійність | Покриття Unit-тестами бізнес-ядра | $\ge$ **75%** (Unity Test Framework) |
