## Зведена матриця нефункціональних вимог (NFRs Matrix)

| Ідентифікатор | Категорія | Інженерний параметр / Метрика | Цільове значення |
| :--- | :--- | :--- | :--- |
| **NFR-1** | Продуктивність | Цільовий фреймрейт рендерингу | **60 FPS** ($\le 16.6$ мс/кадр) |
| **NFR-2** | Швидкодія | Latency подій у Event Bus (p95) | $\le$ **5 мс** |
| **NFR-3** | Керування пам'яттю | Виділення оперативної пам'яті (GC Alloc) | $\le$ **10 КБ / кадр** |
| **NFR-4** | Персистентність | Час серіалізації/десеріалізації стану | $\le$ **50 мс** |
| **NFR-5** | Безпека | Верифікація цілісності сейвів | Гешування **SHA-256** |
| **NFR-6** | Надійність | Покриття Unit-тестами бізнес-ядра | $\ge$ **75%** (Unity Test Framework) |
